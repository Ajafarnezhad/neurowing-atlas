## کار با نسخه ساده

1. از ستون سمت چپ یکی از ۱۵ تجربه را انتخاب کن.
2. `تمرین` را بزن. مدل فرمان هدایت را از Teacher یاد می‌گیرد.
3. بعد `آزمون بدون مربی` را بزن؛ در آزمون وزن‌ها ثابت‌اند و Teacher خاموش است.
4. نور، غذا، بو و حرارت را با ماوس بکش و جابه‌جا کن.
5. شدت/جهت باد را تغییر بده یا ابزار لمس را انتخاب و روی خود مگس کلیک کن.
6. مسیر واقعی پرواز به شکل Trail روی Arena می‌ماند.
7. پنل SWC کنار Arena، اسکلت واقعی نورون‌های نگاشت‌شده را می‌خواند و شدت فعالیت مدل را با درخشش نشان می‌دهد.

## تسک سفارشی اجرایی

از تب «سفارشی» یک الگو مانند رانندگی، پارک دوبل، مربع، زیگزاگ یا اسلالوم انتخاب کن. برای مسیر کاملاً دلخواه، نقاط را با ساختار `x,y | x,y | x,y` وارد کن؛ هر دو مختصات بین صفر و یک هستند. مقدار سوم اختیاری، زمان توقف بر حسب ثانیه است: `0.50,0.43,1.2`. تسک ذخیره‌شده به فهرست اصلی می‌رود و از همان موتور تمرین، آزمون بدون مربی، معیار پیشرفت و مدل مستقل استفاده می‌کند.

## ۱۵ تجربه

نور، غذا، بو، باد، گرما، لمس، اسلالوم، مأموریت چندمرحله‌ای، رفت‌وبرگشت، تغییر هدف، ایست‌وحرکت، عدد ۸، قلب، حرف A، `love you` و `hello Amirhossein`.

## یادگیری

بخش پرواز یک کنترل‌کنندهٔ online imitation-learning دارد. در تمرین، خروجی Teacher به‌عنوان هدف یادگیری استفاده می‌شود؛ در آزمون Teacher و update هر دو خاموش‌اند. مدل هر Task جداگانه ذخیره می‌شود و history در LocalStorage می‌ماند.

`تمرین پیوسته ×۵` برای دیدن پیشرفت سریع‌تر طراحی شده است. دفتر پیشرفت، درصد مسیر، خطای هدایت، برخورد و زمان را نگه می‌دارد.

## Connectome و SWC

پروژه همچنان Explorer تخصصی قبلی را حفظ می‌کند. دکمهٔ `نمای تخصصی` امکانات Connectome، Path، Body Mapping، Inspector و Atlas را برمی‌گرداند.

در نمای ساده، SWCهای واقعی برای نورون‌های نگاشت‌شده از API خوانده می‌شوند. **درخشش SWC فعالیت مدل شبیه‌سازی است، نه ثبت فیزیولوژیک زنده.**

Full-Brain Atlas اختیاری است و برای اجرای ۱۵ تجربه لازم نیست.

## ساخت Atlas اختیاری

Preview سریع:

```powershell
python app.py atlas --data "A:\flybrain" --max-segments 32 --workers 4
```

کیفیت بهتر:

```powershell
python app.py atlas --data "A:\flybrain" --max-segments 64 --workers 4
```

یا از `build_swc_atlas_fast_A.bat` و `build_full_swc_atlas_A.bat` استفاده کن. Atlas قابل Resume است و Progress/ETA چاپ می‌کند.

## تست

اگر Node.js نصب است:

```powershell
node tests/flight.test.js
```

تست‌ها ۱۷ Task، اجرای تسک سفارشی، frozen evaluation، persistence، bounded dynamics، اثر باد و نوشتن مسیر را بررسی می‌کنند.

## مرز علمی

- **واقعی از دیتاست:** Root ID، labels، connection/synapse counts، tags، neuropils، raw synapse points و SWC.
- **مدل آزمایشی:** firing dynamics، mapping حسی/حرکتی، فرمان پرواز و learning.

پس این پروژه یک محیط پژوهشی/آموزشی مبتنی بر Connectome است، نه شبیه‌سازی کامل زیست‌فیزیکی یک مگس واقعی.
